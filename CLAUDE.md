# estudiodaw.dev

Web de apuntes de DAW para compartir con la clase. Ver `README.md` para la estructura del contenido.

## Regla principal

**La web se gana con contenido.** Después de la v1, lo que se toca es contenido (temas nuevos, correcciones), no código. Un tema entra en la web cuando está estudiado y sus ejercicios hechos. Si hay un mes sin nada que publicar, el problema no es la web.

## Fuera de alcance hasta que haya 3 temas publicados

Diseño propio y animaciones, búsqueda de texto completo, editor o ejecución de código, modo de progreso o login, i18n, comentarios.

## Qué NO se publica

- Las soluciones de las **tareas oficiales evaluables** de la plataforma. Solo ejercicios de práctica y sus soluciones.
- Material de educa.jcyl copiado tal cual. Los apuntes van con palabras propias.

## Convenciones

- Español peninsular. En texto español no se usa "—" como separador; ":" o ";". La raya solo como paréntesis.
- Identificadores de código en inglés; comentarios en español, solo donde expliquen un porqué.
- Sin "Co-Authored-By" en los commits.
- Los markdown de origen viven en `Desktop/DAW/2do curso - 2027/<módulo>/mis apuntes/`. Aquí van copias con frontmatter; los originales no se tocan desde este repo.
